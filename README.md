# Jay Kumar Roy — Developer Portfolio

Personal portfolio website built with modern HTML5, vanilla CSS, and JavaScript. Designed with a dark editorial aesthetic, custom typography, micro-interactions, and responsive layouts.

- **Live URL:** [jaykumarroy.github.io](https://jaykumarroy.github.io) *(or your deployed domain)*
- **Role:** Software Developer & AI/ML Engineer
- **Education:** B.Tech in Computer Science (AI & ML) @ Pimpri Chinchwad University, Pune

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3 (Custom properties, CSS Grid, Flexbox, Keyframes), Vanilla JavaScript (ES6+)
- **Typography:** Bebas Neue, Inter, Space Mono, Outfit (Google Fonts)
- **Icons:** Devicon, Font Awesome 6
- **Forms:** Formspree AJAX integration

## ✨ Features

- **Editorial Design System:** High-contrast typography, dark/light theme switching with local storage persistence.
- **Floating Island Navigation:** Pill-shaped glassmorphic navbar with active scroll spy and mobile drawer.
- **Interactive Services:** Auto-cycling service cards with animated progress indicators and pause-on-hover.
- **Curated Projects Bento:** Showcasing mobile apps (React Native, Supabase), full-stack web platforms (PHP, MySQL), and tooling.
- **Performance Focused:** Zero framework bloat, fast load times, semantic HTML5, and responsive down to 320px screens.

## 💻 Running Locally

No build tools or bundlers required. Run with any local HTTP server:

```bash
# Using VS Code Live Server extension (Right-click index.html -> Open with Live Server)

# Or using Python 3
python -m http.server 3000

# Or using Node / npx
npx serve .
```

Then open `http://localhost:3000` in your browser.
